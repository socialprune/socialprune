# SocialPrune

SocialPrune helps people review and clean up their old posts and comments on X and Instagram. It reads the platform's official data export on the user's device; a person makes every delete decision and does the final click on the platform.

Early development. The parsers, the import, the review in the browser and the CLI with its local review and agent commands are built and tested on generated data. Nothing is published or deployed yet, and the export guide's facts still wait for a person to check them, so nothing is usable for end users.

The repository holds generated test data only, never real exports.
